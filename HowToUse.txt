
HOW TO IMPORT DATASETS
1- Include "Dataset.h"
2- create Dataset object and use loadCsvFile to read csv file
3- Use get_as_tensor method to return 2 Tensors (data and labels)
4- use rx::Utility::normalize to normalize data
5- use rx::Utility::labelEncode to encode non-numerical data
6- By default all datasets are CSVs directory

HOW TO USE NETWORK
1- Include "Networks/Network.h"
2- inisalize the model using rx::initNet(rx::TYPE)
3- There are 3 types of networks.
*BINARY_CLASSIFICATION:
$ used when possible output is 0 or 1 (eg: diseases)
$ It uses Binary-cross-entropy as loss function
$ Sigmoid function as output activation function
$ relu hidden activation function


*CROSS_CLASSIFICATION:
$ used when predicting multpile categories (eg: Species)
$ It uses Cross-entropy as loss function
$ Softmax as output activation function
$ relu hidden activation function


*REGRESSION:
$ used when predicting contineous data (eg: Prices)
$ It uses mean loss function
$ No output activation function
$ relu hidden activation function

4- Add layers using addLayer method and pass input and output size 
(set last parameter to False to disable bias)
5- Pass the data to the model using Net::PassData function
6- using setLr to set learning rate (obligated)
7- use train method to start training (set 2nd parameter to true to see epochs and loss)
(set last parameter to true to see current accuracy)


8- If using BINARY_CLASSIFICATION you can use 
rx::Utility::accuracy(Net::round(Model.predict(x).values())) 
to see accuracy (use (Model.predict(x).T().values())) if this does not work
